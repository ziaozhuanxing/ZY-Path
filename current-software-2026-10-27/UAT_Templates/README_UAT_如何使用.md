# UAT材料使用说明

真实研究用ZY_Path_UAT_Questionnaire.docx/PDF和ZY_Path_UAT_Data_and_Scoring.xlsx。真实工作簿仍为空，录入同意参与者的匿名原始答卷后自动计分；SUS每人10题全为1–5整数才计分，再汇总均值/标准差/中位数/范围。未使用的功能不当低分，独立完成和辅助完成分开统计。

SUS_Scoring_Checks_SYNTHETIC.xlsx是独立的公式校验文件：只有边界、中性、混合、缺失、越界的6个数学测试向量，不代表6名参与者，不产生可用性结论，不能作为UAT实测数据提交。没有虚构人口特征、访谈引文或任务完成时间。

招募计划为8–10名教育/研究目标用户，实际人数以真实参与者为准。开始前按附录B确认学校要求、参与同意与材料来源；完成一次统一说明后做T01–T10，再填写SUS与功能评价。原始答卷留存，评估样例不得混入实际结果表。
